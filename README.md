# Project: Linked Lists (The Odin Project: JavaScript Course)

In this assignment I built a factory function for the creation of linked lists. You can:

- add/remove nodes from start/end or custom locations
- check size or return string representation
- return head or tail nodes
- find nodes based on index or value

Creating a linked list on my own, I now understand more clearly the difference between other data structures like an array for example. Besides the head, you cannot just directly access a node. After carrying out functions and changing the content, you cannot just use a console.log with the variable name to see the content. Solving these problems is not hard but shows the difference.

Based on [The Odin Project](https://www.theodinproject.com/lessons/javascript-linked-lists) assignment.

## Run

`node main.js`
